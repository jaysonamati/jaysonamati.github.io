<p>Prodigious dimensions of abstraction<br>
<span class="here">here,</span><br>
where rules become suggestion<br>
<span class="here">here;</span><br>
when recognition precedes conversation<br>
<span class="here">here:</span><br>
when memory precedes interaction<br>
<span class="here">here...</span><br>

<span class="here">here.</span><br>

<p>Only<br>
allow it<br>
allow oneself</p>

<p class="coda">play on<br>
pray oh<br>
